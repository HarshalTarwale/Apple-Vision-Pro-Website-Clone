# Apple Vision Pro Website

A modern Apple Vision Pro landing page clone built with HTML, CSS, and JavaScript. The project recreates a premium product showcase experience with smooth scrolling, full-screen video sections, Apple-style navigation, animated content blocks, and immersive visual storytelling.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger
- Locomotive Scroll
- Remix Icon

## Pages And Features

### Header And Navigation

- Apple-style top navigation with product categories.
- Secondary product navigation for Apple Vision Pro.
- Call-to-action buttons for booking a demo and buying.
- Hero video section with Apple Vision Pro branding.

### Intro Section

- Short product introduction focused on spatial computing.
- Full-width background video for a premium visual experience.
- Clean typography inspired by Apple's product pages.

### Product Preview

- Apple Vision Pro logo and product image.
- "Take a Closer look" button.
- Minimal layout that keeps the product as the main focus.

### Experience Sections

- Entertainment section with immersive theater-style video.
- Productivity section showing workspace-focused content.
- Photos and Videos section for memory and media experiences.
- Connection section for communication and shared space.
- Apps section showing app-based use cases.
- visionOS section introducing the spatial operating system.

### Detail Content Blocks

- Text sections paired with each main experience area.
- Large headings and supporting paragraphs.
- Reusable content layout for consistent page flow.
- Learn-more style buttons for product storytelling.

### Design And Technology Sections

- Design section describing the Apple Vision Pro form and build.
- Full-screen design innovation video.
- Technology section highlighting displays, spatial audio, chips, cameras, and sensors.

### Animations And Interaction

- Smooth scrolling with Locomotive Scroll.
- Scroll-based animation support using GSAP ScrollTrigger.
- Looping autoplay videos for immersive page transitions.
- Responsive visual sections for a modern product showcase feel.
